# CurioStar — Free Astrology Curiosity Website

A fun, beginner-friendly astrology website for personality, past patterns and possible future themes.

## Files
- index.html
- style.css
- script.js

## Publish for ₹0
Use GitHub Pages:
1. Create a free GitHub account.
2. Create a public repository named `curiostar`.
3. Upload the three files.
4. Settings → Pages → Deploy from branch → main → root.
5. Your free website will be available at your GitHub Pages address.

## Customize
Change the name "CurioStar", text, colours and content in `index.html` and `style.css`.
